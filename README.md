# Hello World

AI engineer and full-stack developer in Berlin. I build systems end to end: data pipelines, backends, frontends, and the deployment around them.

The workflow is AI-augmented. I own the architecture and the tests, let agents write a lot of the code, and check their output before it ships. Around that I run a private set of agent skills: session rituals that carry state across sessions so work resumes where it stopped, and test-first and verification steps that agents have to pass before a change counts as done. After that it goes into my own end-to-end testing. The last test is always done by a human, and that human is me.

This is the personal account. Most of my work is client code that lives in their repos or under NDA and cannot be shown, so what is here is the side of the desk I can publish: projects I built for myself and engineered properly because I was going to run them. The pinned repos are the ones worth opening first. They come with a plan folder, real test counts, and CI rather than a demo.
